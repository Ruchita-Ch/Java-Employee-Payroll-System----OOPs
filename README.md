# Employee Payroll Management System

A **Core Java-based Employee Payroll Management System** designed to manage employee information and perform salary-related operations using Object-Oriented Programming principles.

## 📌 About the Project

The Employee Payroll Management System allows users to manage employee details, handle different types of employees, and calculate salaries based on employee roles.

The main objective of this project was to strengthen my understanding of **Object-Oriented Programming in Java** and apply OOP concepts to a practical real-world problem.

## 🚀 Features

* Add employee details
* Manage different types of employees
* Calculate employee salary
* Display employee information
* Perform payroll-related operations
* Store and manage multiple employees
* Handle different salary calculation rules

## 🧠 OOP Concepts Implemented

### 1. Encapsulation

Employee data is kept private and accessed through appropriate methods.

### 2. Inheritance

Different employee types inherit common properties and behaviors from a base `Employee` class.

Example:

```text
Employee
   ├── FullTimeEmployee
   ├── PartTimeEmployee
   └── ContractEmployee
```

### 3. Abstraction

Common employee behavior is defined through an abstract class while specific salary calculations are implemented by individual employee types.

### 4. Polymorphism

Method overriding is used to provide different salary calculation behavior for different types of employees.

### 5. Constructors

Constructors are used to initialize employee objects with the required information.

### 6. Collections

Java Collections are used to store and manage multiple employee objects.
